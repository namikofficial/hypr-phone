# Contributing

## How to contribute
- Open an issue first for significant changes so scope and approach are clear.
- Fork the repo, create a focused branch, and submit a pull request with a clear description.
- Keep changes scoped, include tests when relevant, and ensure `cargo check` passes.

## Credit and attribution expectations
- Keep existing author attributions, notices, and project history intact.
- If you build on prior work, acknowledge it in commit messages, PR descriptions, or code comments where appropriate.
- By contributing, you agree your contribution may be publicly credited by your GitHub handle/name in release notes, changelogs, or acknowledgements.
